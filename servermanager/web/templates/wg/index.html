Einrichtung

  1. Einstellungen links ausfüllen und speichern.
  2. RouterOS-Befehle (unten) im MikroTik-Terminal ausführen - sie legen Interface, Firewall, API-Benutzer und den Peer des Servermanagers an.
  3. Public Key des MikroTik eintragen (oder nach Schritt 4 per API übernehmen).
  4. Tunnel aktivieren und API testen.
