Rollen & Berechtigungen

Administrator
Vollzugriff auf alle Systeme, Benutzer, Einstellungen, WireGuard, Backups und Updates.
Manager
Kann Systeme hinzufügen und Enrollment-Tokens erstellen; eigene neue Systeme erhalten automatisch Vollzugriff.
Benutzer
Nur zugewiesene Systeme.
– Lesen
Status, Update-Übersicht, Logs ansehen.
– Bedienen
Zusätzlich Updates installieren, Dienste/Container/VMs steuern, Neustart, Wartung planen, Konfig-Backups erstellen.
– Vollzugriff
Zusätzlich beliebige Befehle, Release-Upgrade, Core-Updates, Zugangsdaten ändern, Backups wiederherstellen, System entfernen.
