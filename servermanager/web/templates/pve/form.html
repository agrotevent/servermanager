Token auf dem Proxmox-Host anlegen (Rechte-Trennung aus, Rolle PVEAdmin auf /): 
pveum user add servermanager@pve
pveum acl modify / --users servermanager@pve --roles PVEAdmin
pveum user token add servermanager@pve sm --privsep 0
Oder automatisch: Proxmox-Host als System verknüpfen, speichern und „Token per SSH einrichten“ klicken.
